# SOHAR SAND INTERNATIONAL TRADING (SSI)

Corporate website for **SOHAR SAND INTERNATIONAL TRADING**, an Oman-based trading company in Al Buraimi (CR No. 1299862).

Built with React, Vite, React Router DOM, and Lucide React icons.

## Requirements

- Node.js 18+ recommended
- npm 9+ recommended

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the local URL shown in the terminal (default: `http://localhost:5173`).

## Production Build

```bash
npm run build
npm run preview
```

## Project Structure

```text
src/
  assets/           # SSI logos and business images
  components/       # Navbar, Footer, Hero, ProductCard, ContactForm, SectionTitle
  pages/            # Home, About, Products, Services, Strength, Contact
  data/             # Editable products.js and services.js
  styles/           # Global and section CSS
  App.jsx
  main.jsx
```

## Editable Content

- Products and categories: `src/data/products.js`
- Services and strengths: `src/data/services.js`
- Logos: `src/assets/logo.png`, `src/assets/logo_footer.png`

## Notes

- Contact telephone, email, and street address are intentionally omitted until verified by the company.
- Google Maps is reserved as a placeholder until a verified location is provided.
- Social media links are omitted until official accounts are supplied.
